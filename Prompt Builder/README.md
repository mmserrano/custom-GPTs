# 🧠 C.R.A.F.T. Prompt Builder

## Overview

**C.R.A.F.T. Prompt Builder** is a specialized version of ChatGPT designed to create **high-quality, expert-level prompts** for large language models (LLMs) like ChatGPT, Claude, Gemini, and others. It helps users generate prompts that are **clear, detailed, and purpose-driven**, ensuring the best possible output from the model.

This GPT is not a general-purpose chatbot. Instead, it serves as a **prompt engineering expert** that guides users through the structured design of world-class prompts using the **C.R.A.F.T.** methodology.

---

## 🔍 What Does It Do?

The C.R.A.F.T. Prompt Builder helps you:

- Design complete, unambiguous prompts for advanced language models.
- Break down the structure of an ideal prompt using the **C.R.A.F.T.** framework:
  - **C**ontexto
  - **R**ol
  - **A**cción
  - **F**ormato
  - **T**arget Audience (Público objetivo)
- Create prompts that include goals, tone, audience details, formatting, and knowledge requirements.
- Produce structured outputs that are easy to follow and implement.

---

## 🧩 Key Features

- 🏗️ **Framework-based Prompt Design**: Uses the structured C.R.A.F.T. format for clarity and precision.
- 🎯 **Customization**: Asks for user input before starting, to adapt prompts to specific needs or contexts.
- 📚 **Context-aware Guidance**: Helps refine vague ideas into robust, production-ready prompts.
- 💡 **Best Practices Embedded**: Incorporates prompt engineering principles used by top professionals.
- 🗣️ **Multilingual-Friendly**: Can create prompts in any language upon request.

---

## 🛠️ How to Use

1. **Start with your idea**: Provide a topic or concept you want to develop into a prompt.
2. **Answer clarification questions**: The GPT may ask you for more details (e.g., audience, format, objective).
3. **Receive your final prompt**: It will deliver a beautifully structured prompt using the C.R.A.F.T. format.
4. **Copy & paste into ChatGPT or another LLM**: Use the prompt to get the most effective response possible.
